Trade Tracker - Android app (installable web app)

Files (upload all 7 together, no folders):
  index.html, manifest.webmanifest, sw.js,
  icon-192.png, icon-512.png, icon-maskable-512.png, README.txt

Put it online (free, GitHub Pages):
  1. Sign in at github.com (or create a free account).
  2. Create a new repository, e.g. "trade-tracker". Make it Public and tick "Add a README file".
  3. In the repository: Add file > Upload files > select all the files above > Commit changes.
  4. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
  5. After a minute or two the app is at https://YOUR-USERNAME.github.io/trade-tracker/

Install on your Android phone:
  1. Open that link in Chrome.
  2. Tap the three-dot menu > "Install app" (on some phones: "Add to Home screen" > Install).
  3. Open Trade Tracker from your home screen. It works offline.

Your data:
  Trades are saved on the phone only, not in the repository. Use "Back up trades" at the bottom
  of the app now and then, and "Restore from backup" on a new phone.
